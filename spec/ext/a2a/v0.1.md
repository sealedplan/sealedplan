# sealedplan A2A extension, v0.1

This page is the URI of the sealedplan A2A extension:

```
https://github.com/sealedplan/sealedplan/blob/main/spec/ext/a2a/v0.1.md
```

Agents declare it in `capabilities.extensions`, and clients activate it with the
`A2A-Extensions` header. Task metadata for the extension is stored under the same URI.

The extension is defined in [SPEC §13, A2A binding](../../SPEC.md#13-a2a-binding-a2a-100).
Objects follow the [JSON Schemas](../../schemas) of spec version 0.1. A new major version
of the spec gets a new page and a new URI (§15).
